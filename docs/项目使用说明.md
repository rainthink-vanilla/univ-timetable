# 大学课表（md 版）· 项目使用说明

> 面向使用者。全程约 10 分钟，其中爬取由 agent 完成，你只需要填表和点几下。

---

## 一、这个项目是什么

你在学校教务系统里的课表，可以变成手机上一个干净的课表 App。

做法是：**你填一张表 → agent 去教务系统帮你抓课表 → 生成一个文件 → 手机 App 导入**。

App 本身不碰你的账号密码，只负责显示课表。

---

## 二、你需要准备

| 准备项 | 说明 |
| --- | --- |
| 手机 | Android 手机（APK 安装）；iOS 需自行构建或用 Expo Go |
| 一个能读文件、能操作浏览器的 agent | 如 Claude Code、Cursor、各类支持工具调用的 agent |
| 学校教务系统地址 + 学号 + 密码 | 填进 `.md` 文件用 |
| 项目里的两个引导文件 | `docs/01-用户信息表与爬取引导.md`、`docs/02-课表更新爬取引导.md` |

---

## 三、安装 App

1. 把 `univ-timetable-1.0.0.apk` 传到手机。
2. 手机点开安装（首次需要允许「安装未知来源应用」）。
3. 打开 App，看到底部三个标签：**课表 / 导入 / 设置**。

> ✅ 当前版本 `1.3.0`（`univ-timetable-1.3.0.apk`，EAS 云构建，已签名）已包含「文件导入」
> 与「按周次列表」，并修复了灵动岛文字裁切的显示问题。若装的是更早版本，请升级到本版本。

---

## 四、首次导入课表（完整流程）

### 第 1 步：填写用户信息表

打开 `docs/01-用户信息表与爬取引导.md`，复制一份，填写第 1 节：

| 项目 | 你填写 |
| --- | --- |
| 学校名称 | 示例大学 |
| 教务系统登录地址 | https://jwc.example.edu.cn/login |
| 课表页地址 | 可留空 |
| 学号 / 账号 | 20250001 |
| 密码 | 你的密码 |
| 学期 | 2025-2026 学年第一学期 |
| 学期开始日期 | 2025-09-01 |
| 学期总周数 | 20 |
| 本次爬取范围 | **all**（首次导入选 all，抓整学期） |

> **爬取范围怎么选？**
> - 第一次导入 → `all`（整学期，最完整）
> - 以后每周更新 → `week`
> - 每月更新 → `month`
> - 只看今天 → `day`
> - 补抓某几周 → `custom` + 填周次

### 第 2 步：让 agent 干活

对 agent 说：

> 按 `01-用户信息表与爬取引导.md` 第 3 节执行，产出第 4 节格式的文件。

agent 会：登录 → 找到课表页 → 按范围抓取 → 自查 → 生成 `课表-<学校>-<学号>.md`。

如果遇到验证码，agent 会让你手动输入。

### 第 3 步：导入 App

1. App →「导入」→「文件导入」；
2. 点「📂 选择文件」，选刚才生成的 `.md`；
3. 检查预览：课程数量对不对？星期/节次/周次对不对？可以取消勾选不想导入的课；
4. 导入方式选 **「更新合并」**（首次也可以，效果等同）；
5. 点「导入已选课程」。

### 第 4 步：⚠️ 改密码（重要）

导入成功后 App 会弹提醒：

> 安全提醒：agent 刚才用你的账号密码登录过教务系统……建议现在就去修改密码。

点「去改密码」会跳到教务系统。**改密码不影响已经导入的课表**，因为课表已经存在手机本地了。

顺手把 `.md` 文件第 1 节的密码行清空，或直接删掉这个文件。

## 五、导入方式详解

### 方案 A：文件导入（推荐）

App →「导入」→「文件导入」→ 选文件 → 确认。

**导入方式三选一：**

| 方式 | 什么时候用 |
| --- | --- |
| **更新合并** | 日常更新课表（默认）。文件里有几门课就更新几门，其他课程不动 |
| **整体替换** | 换学期、或课表大改。会清空现有课表 |
| **追加** | 手动补几门课 |

### 方案 B：粘贴文本（备用）

1. 用文本编辑器打开 agent 生成的 `.md`；
2. 找到 ```` ```json ```` 代码块，把里面的内容整段复制；
3. App →「设置」→「导入课表 (JSON)」→ 粘贴 → 解析并导入。

> 新版 App 也支持直接把**整份 `.md` 文件内容**粘进去，会自动识别。

### 方案 C：AI 导入（兜底）

只有课表截图或一段文字、没有文件时用：App →「导入」→「AI 导入」，先到「设置 → AI 服务」填一个 API Key（DeepSeek / OpenAI / 通义千问等）。

## 六、日常使用

### 看课表

课表页顶部有 **日 / 周 / 全** 三个视图，随时切换：

| 视图 | 说明 |
| --- | --- |
| **日** | 左右滑动切换周一到周日，自动高亮「今天」和「正在上课」 |
| **周** | 7 天 × 节次的网格，一眼看完整周；**左侧时间栏标出每一节的开始时间与结束时间**；课程块里**地点会自动换行、尽量显示全** |
| **全** | **按周次列出整个学期**：每周一块，块头是「第 N 周 + 日期区间」；当前周带「本周」角标并高亮；点右下角「回到本周」一键跳回当前周 |

> **同一时间有两门课时**（例如都排在 1-2 节），两块会**并排显示、各占半列**，
> 都看得见也都能点，不会互相遮挡；不重叠的课仍然占满整列。

「全」视图用来**提前查看整个学期的课**——想确认第 10 周有没有课、某门课什么时候结束、
某周是不是放假没课，直接滑到那一周看即可；那一周没有课时会显示「这一周没有课」。

> 周数按「设置的总周数」和「课表实际排到的最大周次」中较大的那个显示，
> 因此即使课表排到了设置周数之后（如重修课排到第 20 周），也不会被截掉。

### 周次预览（提前看未来某周）

课表页标题下方有 **「🔍 周次预览」** 按钮，点开后会以**正常课表的样子**（7 天 × 节次的网格）
显示指定的一周：

- **‹ 上一周 / 下一周 ›** 左右切换；
- 中间一排数字胶囊可直接跳到第 N 周（没有课的周会淡显）；
- 标题显示「第几周 + 日期区间 + 这门周有几门课」，当前周带「本周」角标；
- 那一周没有课时显示「这一周没有课」。

和「全」视图的区别：**「全」是整学期的平铺列表，用于扫视；「周次预览」是聚焦某一周的完整课表，
用于细看**（比如想确认下周周三下午有没有课）。

顶部「灵动岛」胶囊显示当前第几周、今天日期和下一节课；点一下可展开看上课时间、教师和地点。

### 手动改课

- 课表页右下角 **＋** 快速添加；
- 点已有课程卡片可以编辑或删除；
- **星期可以多选**：点几个星期就勾几个，按钮会提示「添加到课表（N 天各一条）」——
  一门课选 3 天，就会在课表里生成 3 条（每天一条），方便单独调整某一天；
  编辑已有课程时，原来那天优先沿用，新勾选的天各新增一条。

### 改设置

「设置」页可以调。**v1.7.1 起设置项按功能分成六类，每类可以点标题展开 / 收起（分类抽屉）**：

| 分类 | 里面有什么 |
| --- | --- |
| **学期与作息** | 学期开始日期、设为本周一、学期总周数、**节次时间表** |
| **外观与主题** | 强调色、灵动岛、毛玻璃（预留）、**自定义主题**（背景图 / 三个标签图标） |
| **AI 服务** | 五个服务预设、服务地址、API Key、文本模型、视觉模型 |
| **课表来源（教务系统）** | 登录地址、课表页地址、备注、最近一次导入信息 |
| **分享与接收课表** | 把课表发给同学 / 收同学的课表 |
| **数据管理** | 导出课表 (JSON)、导入课表 (JSON)、**课表自检**、清空所有课程 |

- 每个分类**标题下面有一行摘要**，收起时也能一眼看到这一类的当前状态（如「20 周 · 节次 12 节」）；
- 页面顶部的 **「分类折叠（抽屉）」** 开关：**关掉后所有分类一次性平铺展开**（不再折叠），
  喜欢一屏看全的可以关掉它，设置会被记住。

各设置项说明：

| 设置项 | 说明 |
| --- | --- |
| 学期开始日期 | 决定「现在是第几周」，导入文件会自动填 |
| 学期总周数 | 默认 20 |
| **节次时间表** | **各校上课时间不同**（有的第 1 节 8:00、有的 8:30），按学校实际改；导入的文件若带节次时间，会自动同步过来 |
| 强调色 | 界面主色：按钮、胶囊选中态、底部标签高亮、右下角 ＋ 按钮等，**选中即刻生效，不用重启** |
| **自定义主题** | 上传自己的背景图与图标（见下方说明），背景遮罩可调 |
| 灵动岛开关 | 顶部胶囊 |
| **分享与接收课表** | 把课表发给同学 / 收同学的课表（见下方说明） |
| 导出课表 (JSON) | 备份 / 换机迁移 |
| 清空所有课程 | 慎用，二次确认 |

### 一门课一周上两天怎么填

课表数据里可以把"一周上两天"写在一格里，App 会**自动拆成两天各一条课程**：

| 写法 | 结果 |
| --- | --- |
| `周六、周日` / `周六/周日` / `周六和周日` | 周六 + 周日各一条 |
| `六日` / `周六周日` / `6,7` / `6-7` / `周六-周日` | 周六 + 周日各一条 |
| `周末` / `双休` | 周六 + 周日各一条 |
| `工作日` / `一至五` / `周一到周五` | 周一到周五各一条 |
| `每天` / `全周` | 周一到周日各一条 |
| `0` | 按**周日**处理 |

> 拆出来的几条**互不关联**：想单独改周日那一条（比如换教室）不会影响周六，这正是我们想要的。
> v1.7.1 修的就是"只有周六生效"的问题——旧版遇到这种写法只会认第一个星期。

### 课表显示不对？先跑一次「课表自检」

「设置 → 数据管理 → 课表自检」会检查并告诉你：

| 报告内容 | 用途 |
| --- | --- |
| **按星期分布** | 例如「周一 3 · 周二 2 · … · **周日 0**」——一眼看出某天是不是空的 |
| 同一天同一时段、同名同地点的重复 | 多半是"一门课写了两天、但只被识别成一天"留下的痕迹 |
| **周六有课、周日没有任何课程** | 会直接给出修复建议 |
| 星期字段不规范 | 列出原值（如 `0`、`"周日"`），并说明已按哪个星期显示 |
| 没有周次信息 / 重复 id / 节次超出作息表 | 其它会导致"看不到课"的原因 |

- 报告可以点 **「分享自检报告」** 发出来（发给同学或自己，便于排查）；
- 装好新版本后**先打开一次 App**：启动时会自动把历史数据里不规范的星期写法改正（例如 `0`、`"周日"` → 周日）。

> **如果课表还是不对**：把「课表自检」的报告发我，里面会直接写明是数据问题还是显示问题。

### 自定义主题（背景图 / 图标）

「设置 → 自定义主题」可以换成你自己的图片：

| 图片要求 | 规格 |
| --- | --- |
| 格式 | JPG / PNG / WebP |
| 体积 | ≤ 20 MB（超过 8 MB 会提示"载入稍慢"） |
| 尺寸 | **最短边 ≥ 120px 就能用**；建议 ≥ 1080px 才算清晰（600px 以上够用） |

- **偏小的图不会被拒绝**：只要不低于 120px 就可用，只是会提示"放大后可能模糊"；
- 清晰度按**裁剪之后的实际尺寸**评价：清晰 / 够用 / 偏小 / 很小，界面上会实时显示；
- **选好图后会进入裁剪**（详见下方「图片裁剪」）；
- **背景遮罩**：5 档可调。背景图越花，越要调深才能看清文字；
- **应用内图标**：底部三个标签**都能单独换**（见下）；
- 选好后图片会被**复制进 App 自己的目录**，所以之后你把相册里的原图删掉也不影响。

#### 图片裁剪

选中图片后，App 会打开裁剪界面，让你**自己决定保留哪一块**：

| 操作 | 说明 |
| --- | --- |
| 拖动图片 | 调整位置 |
| **双指捏合** | 放大 / 缩小（可同时用两指拖动） |
| **＋ / －** | 按钮缩放（不方便双指时用），点「重置」回到初始状态 |
| 比例胶囊 | 背景图：**全屏（推荐，按手机屏幕比例）/ 9:16 / 1:1**；图标固定 1:1 |
| 目标尺寸 | 显示「该比例建议 ≥ 1080 × 1920」，以及当前裁剪后的实际像素与分级结论 |
| 使用这张 | 确认并立即应用（**不用重新选图**） |

- **按建议尺寸裁到位就能清晰使用**；裁得太小时会提示，可点「重置」或把范围往外拉；
- 已经设置好的图片，随时可点 **「重新裁剪」** 再调整；
- **裁剪不改动原图**：只记录"取哪一块"，所以反复裁剪**不会越裁越糊**，也能反向把范围拉大。

#### 应用内图标（底部三个标签都能换）

「设置 → 自定义主题 → 应用内图标」里有**三个图标槽**（课表 / 导入 / 设置）：

1. 点一下要改的那个标签槽；
2. 然后可以 **上传图标图片**（会自动进入 1:1 裁剪）、或 **直接选一个 emoji**、
   或 **恢复该标签的默认图标**；
3. 三个标签互相独立，改一个不影响另外两个。

> ℹ️ 手机桌面上的 App 图标仍**无法**在应用内更换——它由安装包决定，需要重新打包才能改。

> ℹ️ **手机桌面上的 App 图标无法在应用内更换**——它由安装包决定，需要重新打包才能改。
> 这里自定义的是**应用内**的背景与图标。

### 分享课表给同学 / 接收同学的课表

「设置 → 分享与接收课表」：

**分享出去**

- **分享课表（系统分享面板）**：弹出发送面板，可发微信 / QQ / 邮件等；
  面板里也能直接选「复制」，把课表粘到聊天窗口；
- **分享简版文本**：按天分组列出（时间 + 课程 + 地点），适合直接发聊天窗口；
  文本末尾附一段机器可读内容，**对方整段粘回 App 即可还原**。

分享的内容包含**课程、节次时间、学期信息**，以及**主题配色**（强调色、遮罩、图标）。

**接收同学的课表**

1. 点「接收同学的课表文件」，选中对方发来的 `.md` 文件；
2. App 会先显示**将导入多少门课**、是否含节次时间/主题，并列出课程预览；
3. 然后由你选择：
   - **导入课表（用我自己的主题）**——只拿课表，保留你自己的外观；
   - **导入课表 + 应用对方主题**——连对方的配色一起套用；
   - 取消。

> 导入默认按「更新合并」处理：同一天同一节次的同名课程会被新数据覆盖，其余保留，
> 所以收同学的课表不会把你现有的课冲掉。

## 七、更新课表（第二次以后）

1. 打开 `docs/02-课表更新爬取引导.md`，只填 4 行：教务系统地址、学号、密码、**爬取范围**；
2. 对 agent 说：按 `02-课表更新爬取引导.md` 执行更新；
3. 得到 `课表更新-<学号>-<日期>.md`；
4. App → 导入 → 文件导入 → 选文件 → **导入方式务必选「更新合并」**；
5. 改密码。

> ⚠️ 窄范围更新（`day`/`week`/`month`/`custom`）**不要**选「整体替换」，否则课表会只剩那几门课。

## 八、常见问题

**Q1：装不上 APK？**
允许「安装未知来源应用」；或用 `npx expo start` 配合 Expo Go 扫码运行。

**Q2：点了「选择文件」提示不支持？**
说明装的是旧版 APK（`1.0.0` 那版没有文件导入）。装 `univ-timetable-1.3.0.apk`，或先用方案 B 粘贴导入。

**Q3：导入后课表是空的？**
检查文件里有没有 ```` ```json ```` 代码块或「课程明细」表格；表格里必须同时有 星期 和 节次 两列。

**Q4：周次不对（比如显示第 99 周）？**
到设置里改「学期开始日期」。导入标准文件时会自动填。

**Q5：同一门课导入了两次？**
用「更新合并」重新导一次即可去重；或到设置里清空后重导。

**Q6：某门课被取消了，更新后还在？**
增量更新不会删除文件外的课程。用 `all` 范围 +「整体替换」重建，或手动删除那门课。

**Q7：课表能同步到系统日历吗？**
目前不能，计划中。

**Q8：密码会不会被 App 存下来？**
不会。App 只接收课表数据，不接收账号密码，也不联网上传课表。

**Q9：顶部灵动岛的文字被裁掉/挤在一起？**
那是旧版本的显示问题，已在 `1.2.1` 修好：灵动岛现在按内容自适应高度，并关闭了系统额外的行内边距。
升级到最新 APK 即可。

**Q10：「全」视图里某一周没有课，是不正常吗？**
正常。那一周没有排课就会显示「这一周没有课」。

**Q11：「全」视图显示的周数比我设置的学期周数多？**
是故意的。周数取「设置的总周数」与「课表实际排到的最大周次」中较大的那个——
比如设置 18 周、但某门重修课排到第 20 周，多出来的周次也会显示，避免漏课。
要改周数去「设置 → 学期 → 学期总周数」。

**Q12：App 显示的上课时间和学校实际不一样（比如学校 8:30 上课，App 显示 8:00）？**
各校作息不同，需要按学校实际配置：**设置 → 学期 → 节次时间表**，改第 1 节的开始时间即可。
填在 `docs/01-用户信息表与爬取引导.md` 的「第 1 节上课时间」里也行——agent 会写进课表文件，
导入时自动同步过来。

**Q13：我手动调好的节次时间，更新课表后被打回去了？**
只有**文件里带了节次时间**时才会覆盖。你自己手动改、而更新文件不带节次时间的话不受影响。
如果被覆盖了，说明这次的更新文件带了节次时间——重新在设置里改一次即可。

## 九、安全须知（务必读一遍）

1. **用完就改密码**——agent 登录过你的教务系统，密码可能留在对话记录、浏览器缓存里。
2. `.md` 文件里的密码行，用完整理清空，不要提交到 git、不要发群里。
3. agent 的引导里已经写明「只读、只爬本人课表、禁止写操作、禁止绕过验证码」，但**建议你亲自看一眼 agent 的操作记录**。
4. 课表数据只存在你手机本地，卸载 App 会一起删掉——记得偶尔用「导出 JSON」备份。

**填表 → 让 agent 抓 → 选文件导入 → 改密码。** 之后每周只改一个「爬取范围」就能更新。
