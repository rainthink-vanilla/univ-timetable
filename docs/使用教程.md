# 大学课表 App · 使用教程（从零到用上）

> 面向：第一次用这个 App 的同学
> 预计耗时：**首次约 15–25 分钟**（其中大部分是等 agent 爬完课表）
> 需要准备：一台安卓手机、一个还能登录的教务系统账号、一个能跑 agent 的对话窗口（Claude / ChatGPT / DeepSeek 等任选）

---

## 最短路径（只想赶紧用上）

1. **装 App** → 见 [第一步](#第一步安装-app)
2. **填模板**：把 `docs/01-用户信息表与爬取引导.md` 复制给 agent，填上你的学校与教务系统信息
3. **让 agent 爬** → 它产出一个 `.md` 课表文件
4. **导入 App**：「导入 → 文件导入 → 选择文件」
5. **去改密码**（重要，见 [第五步](#第五步必须做改教务系统密码)）

剩下的个性化（主题、图标、分享）以后有兴致再折腾。

## 第零步：先搞清楚它怎么工作

这个 App **不直接登录你的教务系统**（各校系统差异太大，爬虫很快就会失效）。
它把最容易变化的部分交给通用的 AI agent，自己只负责"把一份稳定的数据画成课表"：

```
你在模板里填学校信息
        ↓
agent 按引导登录教务系统、抓课表
        ↓
产出一个统一格式的 .md 文件（人可读表格 + 机器可读 JSON）
        ↓
App「文件导入」→ 变成手机上的课表（离线可看）
```

**为什么要这么设计**：教务系统改版时，只需要换一段引导提示词，App 不用更新。

## 第一步：安装 App

### 方式 A：直接下载安装包（推荐）

1. 在手机浏览器打开本仓库的 **Releases** 页面，下载最新的 `univ-timetable-x.y.z.apk`；
2. 点击安装包 → 系统可能提示"未知来源应用"，在弹窗里允许**此来源**安装（小米/华为/OPPO 叫法略有不同）；
3. 安装完成后桌面会出现「大学课表」。

> 更新也走同一条路：下载新版 APK **覆盖安装**即可，课表与设置都会保留。

### 方式 B：自己从源码构建

见 [README 的开发与验证章节](../README.md#开发与验证)（需要 Node 环境与 Expo 账号，用 EAS 云构建出 APK）。

### 装好之后先做一件事

打开 App → 底部「设置」→ 「学期与作息」→ 确认**学期开始日期**（开学第一周的周一）与**学期总周数**。
导入课表后这两项通常会被文件自动填好，但现在先看一眼没坏处 —— "现在是第几周"就靠它算。

## 第二步：填写用户信息表

在电脑上打开仓库里的 **`docs/01-用户信息表与爬取引导.md`**，把里面的表复制一份，填上：

| 要填的 | 例子 | 说明 |
| --- | --- | --- |
| 学校名称 | 示例大学 | 给 agent 判断教务系统类型用 |
| 教务系统地址 | `https://jwc.example.edu.cn/` | 浏览器里登录课表的那个网址 |
| 登录账号 | 你的学号 | **只在本地用**，不给 App |
| 登录密码 | 你的密码 | 同上；用完务必改密码 |
| 学期 | 2025-2026 学年第一学期 | 选课表里显示的学期名 |
| 开学日期 | 2025-09-01 | 第一周的周一（不确定就填个接近的） |
| 总周数 | 20 | 一般 18 / 20 |
| 爬取范围 | `all` | `day`/`week`/`month`/`all`/`term` |
| 各节次时间 | 第 1 节 08:30–09:15 … | **各校不同**，填了课表上就显示正确时间 |

> ⚠️ **这份填好的文件不要发给别人、不要提交到 git**，里面是你的账号密码。

## 第三步：让 agent 爬课表

1. 打开一个 agent 对话（Claude / ChatGPT / DeepSeek 等，**需要它具备联网/浏览器能力**）；
2. 把 `docs/01-用户信息表与爬取引导.md` 的**全文** + 你填好的信息一起发给它；
3. 按引导文档里的要求，明确告诉它：**只爬我自己本人的课表**、只读不写、不要做任何修改操作；
4. 它爬完后会产出一个 `.md` 文件（形如 `我的课表-2025秋.md`），保存到电脑或手机。

**这个文件长这样**（四段：元信息 / 节次时间表 / 课程明细表格 / 机器可读 JSON）：

```markdown
## 一、课表元信息
| 学校 | 示例大学 |
| 学期开始日期 | 2025-09-01 |
| 学期总周数 | 20 |

## 二、节次时间表
| 节次 | 开始 | 结束 |
| 1 | 08:30 | 09:15 |

## 三、课程明细
| 课程名称 | 教师 | 地点 | 星期 | 节次 | 周次 |
| 高等数学A | 张三 | 教一101 | 周一 | 1-2 | 1-16 |
| 周末实验 | 王五 | 实验楼A | 周六、周日 | 5-6 | 1-16 |

## 四、机器可读数据
```json
{ "contract": "univ-timetable/v1", ... }
```
```

> 💡 **"周六、周日"这种一格写两天是支持的**，App 会自动拆成周六、周日各一条课。

## 第四步：把课表导入 App

1. 把那个 `.md` 文件传到手机（微信"文件传输助手"、数据线、网盘都行）；
2. 打开 App → 底部「**导入**」→「文件导入」→ 点「**📂 选择文件**」；
3. 选中文件，App 会先解析并**预览**：多少门课、学校、开学日期、节次时间、解析方式；
4. 勾选要导入的课程（默认全选），选导入方式：

   | 方式 | 什么时候用 |
   | --- | --- |
   | **更新合并**（默认） | 日常更新：同一天同一节次的同名课会被覆盖，其它保留 |
   | **整体替换** | 换学期：清空后完全用文件内容 |
   | **追加** | 手动补几门课 |

5. 点「导入已选课程」→ 课表页立刻能看到。

> 没有文件？也可以用「导入 → AI 导入」：粘贴课表文本或传一张课表截图，让 App 自己解析（需先在设置里填 AI 服务）。
> 或者「导出/导入 JSON」：把 JSON 文本直接粘进「设置 → 数据管理 → 导入课表 (JSON)」。

---

## 第五步（必须做）：改教务系统密码

agent 刚才用你的账号密码登录过教务系统，密码可能留在浏览器记录、日志或对话里。

**现在就去改密码**（导入成功的弹窗里有「去改密码」按钮，可以直接跳过去）。
改完密码**不影响**已经导入的课表。

## 日常使用

### 四个看课表的地方

| 位置 | 用途 |
| --- | --- |
| **日** | 左右滑动切换周一到周日；自动高亮「今天」与「正在上课」的课 |
| **周** | 7 天 × 节次的网格；**左侧时间栏标出每节的开始与结束时间**；课程块里地点会自动换行尽量显示全 |
| **全** | 整学期按周列出，点某周的块头可**展开那一周的课表**；当前周高亮，可一键「回到本周」 |
| **🔍 周次预览** | 课表页标题下方入口：以正常课表的样子**提前看未来某一周**，可前后翻周、点数字胶囊直达 |

> 同一时间有两门课时（比如都排在 1-2 节），两块会**并排显示各占半列**，不会互相遮挡。

### 顶部「灵动岛」

显示当前第几周、今天日期和下一节课；点一下可展开看上课时间、教师、地点。不想要就在
「设置 → 外观与主题 → 灵动岛」关掉。

### 改课 / 加课

- **加课**：课表页右下角 **＋**；
- **改课**：点课程卡片 → 详情 → 「编辑」；长按卡片也能直接进编辑；
- **删课**：详情里「删除课程」；
- **星期可以多选**：想让一门课一周上两天，在表单里把两天都勾上，
  按钮会提示「添加到课表（2 天各一条）」—— 会生成两条课程，方便单独改其中一天（比如周日换教室）。

## 个性化外观

「设置 → 外观与主题」：

### 强调色

选一个颜色，界面上的按钮、选中胶囊、底部标签高亮、右下角 ＋ 按钮会**立刻**跟着变。

### 背景图

1. 点「选择背景图」→ 从相册选一张；
2. App 会打开**裁剪界面**：拖动移动、**双指捏合缩放**（也可用 ＋/－）、可选比例「全屏（推荐）/ 9:16 / 1:1」；
3. 界面上会显示**建议目标尺寸**（如 ≥ 1080 × 1920）与"裁剪后 1080 × 1920 · 清晰"这样的评价 —— 按这个尺寸裁就够清楚；
4. 点「使用这张」立即生效；想再调就点「重新裁剪」。

**图片规格**：JPG / PNG / WebP，≤ 20MB，**最短边 ≥ 120px 就能用**（偏小只是提示，不会拒绝）。
裁剪**不改动原图**，所以反复裁剪不会越裁越糊。

### 背景遮罩

背景图太花时，把遮罩调深（60%–92%），文字更清楚。

### 底部三个标签的图标（都能换）

「应用内图标」里有三个槽：**课表 / 导入 / 设置**。

1. 点一下要改的那个槽；
2. 然后「上传图标图片」（会进 1:1 裁剪）、或直接选一个 emoji、或「恢复默认」；
3. 三个标签互相独立。

> ℹ️ **手机桌面上的 App 图标改不了** —— 它由安装包决定，需要重新打包才能换。这里换的是**应用内**的图标。

## 和同学分享课表

「设置 → 分享与接收课表」：

- **分享课表（系统分享面板）**：走微信 / QQ / 邮件，面板里也能直接「复制」；
- **分享简版文本**：按天分组（时间 + 课程 + 地点），适合直接发聊天窗口；
- **接收同学的课表文件**：选对方发来的文件 → 预览 → 选择
  「导入课表（用我自己的主题）」或「导入课表 + 应用对方主题」；
- 导入按**更新合并**处理，不会把你现有的课冲掉。

## 换学期 / 更新课表

1. 用 `docs/02-课表更新爬取引导.md` 让 agent 重新爬（可以只爬指定周次，比如"本周"）；
2. 导入时保持默认的**更新合并**；
3. 换学期建议先「设置 → 数据管理 → 导出课表 (JSON)」备份，再导入新文件并选择**整体替换**。

> 已知行为：增量更新**不会自动删除**教务系统里已取消的课，需要你手动删或整体替换。

## 设置速查

设置页按功能分成六类，**点标题展开 / 收起**（顶部「分类折叠（抽屉）」开关可以关掉这个折叠，改成全部平铺）：

| 分类 | 里面有什么 |
| --- | --- |
| **学期与作息** | 学期开始日期、设为本周一、学期总周数、**节次时间表**（各校作息不同，一定要按学校改） |
| **外观与主题** | 强调色、灵动岛、毛玻璃（预留）、自定义主题（背景图 / 三个标签图标） |
| **AI 服务** | 五个预设（DeepSeek / OpenAI / Moonshot / 通义千问 / 智谱）、服务地址、API Key、模型 |
| **课表来源（教务系统）** | 教务系统地址、课表页地址、备注、最近一次导入信息 |
| **分享与接收课表** | 见上一节 |
| **数据管理** | 导出/导入 JSON、**课表自检**、清空所有课程 |

## 课表显示不对怎么办

先跑一次 **「设置 → 数据管理 → 课表自检」**，它会直接告诉你问题在哪：

| 报告内容 | 说明 |
| --- | --- |
| **按星期分布** | 如「周一 3 · 周二 2 · … · 周日 0」——一眼看出某天是不是空的 |
| 同一天同一时段、同名同地点的重复 | 多半是"一门课写了两天、但只被识别成一天"留下的痕迹 |
| 周六有课、周日没有任何课程 | 会给出"重新导入 / 手动补周日"的具体建议 |
| 星期字段不规范 | 会列出原值（如 `0`、`"周日"`）并说明按哪个星期显示 |
| 没有周次 / 重复 id / 节次超出作息表 | 其它会导致"看不到课"的原因 |

- 点「**分享自检报告**」可以把报告发出来（发给开发者排查最快）；
- 装新版后**先打开一次 App**：启动时会自动把历史数据里不规范的星期写法改正（例如 `0`、`"周日"` → 周日）。

## 常见问题 FAQ

**Q：App 会把我教务系统的密码上传吗？**
不会。密码只存在于你给 agent 的那份 `.md` 里，App 不接收也不存储它。App 不联网同步，课表只存在本机。

**Q：换了手机怎么办？**
旧机「设置 → 数据管理 → 导出课表 (JSON)」→ 把那段 JSON 存下来（发给自己或存文件）→
新机「设置 → 数据管理 → 导入课表 (JSON)」粘贴导入。自定义主题的图片不会跟着走，需要重设。

**Q：课表里的时间不对（比如第 1 节显示 08:00，我们学校是 08:30）？**
「设置 → 学期与作息 → 节次时间表」按学校实际改；如果导入的文件里带了节次时间，会自动同步。

**Q：某天的课跑到别的列去了 / 周六周日显示不对？**
先跑「课表自检」（见上一节）。如果确实是数据写法问题，用原始 `.md` 重新导入一次即可；
报告里会写明是数据问题还是显示问题。

**Q：为什么有些课点开看不到地点 / 教师？**
数据文件里那一格是空的。可以让 agent 重新爬一次，或在 App 里点「编辑」手填。

**Q：能导出到手机日历吗？**
暂不支持（`.ics` 导出在计划中）。

**Q：安卓之外呢（iOS / 网页）？**
代码是 Expo 写的，理论上能出 iOS 包，但本项目只发布过安卓 APK，iOS 未验证。

## 备份、换机与卸载

- **备份**：「设置 → 数据管理 → 导出课表 (JSON)」，把文本存好（含课程、学期、节次时间）；
- **换机**：新机导入上面那份 JSON；
- **卸载**：卸载会**清除本地课表**，卸载前请先导出。
