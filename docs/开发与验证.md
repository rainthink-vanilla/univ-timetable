# 开发与验证

本文面向希望从源码运行、修改或构建大学课表 App 的开发者。产品功能与安装方法见 [README](../README.md)，实现细节见 [项目技术文档](项目技术文档.md)。

## 环境与运行

项目使用 Expo SDK 54、React Native、TypeScript，依赖版本以 `package.json` 和 `package-lock.json` 为准。准备 Node.js 与 npm 后，在项目根目录运行：

```bash
npm ci
npx expo start
```

开发服务器启动后可使用 Expo Go 调试。Android 安装包使用 `eas.json` 中的 `preview` 配置通过 EAS 云构建：

```bash
npx eas-cli build -p android --profile preview
```

云构建需要 Expo 账号及对应的 EAS 项目权限。

## 检查命令

```bash
npm run typecheck   # TypeScript 类型检查
npm test            # 单元测试与两份引导文档的契约校验
npm run verify      # 导出 Web 产物并运行无头浏览器界面断言
npm run verify:apk  # 检查 Android APK 的签名、bundle、原生模块和版本
```

`npm run verify` 需要本机安装 Chrome 或 Edge。`npm run verify:apk` 需要先将 APK 放在项目根目录，也可以直接运行 `node scripts/verify-apk.mjs <APK 路径>`。在限制派生进程的沙箱里，Node 测试、Metro 或浏览器验证可能报 `spawn EPERM`；请在普通终端运行。

当前 v1.7.2 的发布校验记录为：类型检查通过、单元测试 69/69、文档契约 2/2、无头浏览器断言 131/131、APK 校验 13/13。验证脚本会检查文件导入、课程列几何、重叠课程分列等实际行为；`scripts/diff-apk-bundle.mjs` 可用于比较两个 APK 的内嵌 bundle。

## 数据契约

App 优先解析 `univ-timetable/v1` 的 JSON 代码块，其次解析 Markdown 表格，最后尝试宽松解析。文件可同时包含便于人阅读的表格和机器可读 JSON；两者应保持一致。契约支持学期起始日期、总周数、各节起止时间、课程星期与周次，也支持一格多天。

完整字段、示例与爬取引导见 [首次爬取模板](01-用户信息表与爬取引导.md) 和 [更新爬取模板](02-课表更新爬取引导.md)。`npm test` 会用真实解析器检查这两份文档的示例。

## 代码位置

| 路径 | 作用 |
| --- | --- |
| `App.tsx`、`app.json`、`eas.json` | 应用入口、Expo 与 EAS 配置 |
| `src/screens/`、`src/components/` | 课表、导入、设置页面及复用界面 |

| `scripts/test-*.mjs`、`scripts/verify-*.mjs` | 单元、文档、浏览器与 APK 验证 |
