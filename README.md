# 大学课表 · Univ Timetable

一款面向大学生日常使用的 Android 课表 App。把教务系统导出的课程整理成统一文件，导入后就能按天、按周或按整学期查看；课程与设置保存在手机上。

**当前版本：v1.7.2** · [下载 Android 安装包](https://github.com/rainthink-vanilla/univ-timetable/releases/latest) · [完整使用教程](docs/使用教程.md)

## 它怎么工作

各校教务系统差异很大，因此 App 不直接登录学校系统。你可以按[首次爬取模板](docs/01-用户信息表与爬取引导.md)让自己信任的 AI agent 获取课表，生成包含 Markdown 表格和 JSON 的文件，再通过 App 的「导入 → 文件导入」选择该文件。

```text
教务系统 → AI agent 整理 → 课表文件（.md / .json）→ App 导入 → 手机上查看
```

也可以手动添加课程；已有课表文本或截图时，可选择在 App 内使用自己配置的 AI 服务辅助导入。

## 主要功能

- **多种视图**：日视图、7 天周视图、整学期周次列表；可预览任意一周，并提示当前周与下一节课。
- **灵活导入**：预览后选择更新合并、整体替换或追加；支持不同学校的节次时间与「周六、周日」等一格多天写法。
- **个性化**：更换强调色、背景图和应用内标签图标；背景图支持拖动、缩放和重新裁剪。
- **分享与自检**：分享课表文件或简版文本；检查课程星期、重复项及异常周次，便于排查显示问题。

## 三步开始

1. 从 [Releases](https://github.com/rainthink-vanilla/univ-timetable/releases/latest) 下载最新 APK 并安装。
2. 复制[首次爬取模板](docs/01-用户信息表与爬取引导.md)到自己的私有文件，填写学校信息，让可信任的 agent 生成课表文件。
3. 在 App 中选择「导入 → 文件导入」，检查预览后导入；完成后修改教务系统密码。

首次安装、日常使用、更新课表和排错步骤见 [使用教程](docs/使用教程.md)。升级时可用新版 APK 覆盖安装。

## 隐私说明

App 不接收教务系统密码，常规课表数据保存在本机，不提供云端同步。**不要把填写了账号密码的引导文件提交到 GitHub。** 如果使用 App 内 AI 导入，输入的文字或截图会发送到你配置的 AI 服务；分享课表或自检报告也只在你主动操作时进行。

## 当前限制

目前提供 Android APK；iOS 尚未验证。增量导入不会自动删除已取消的课程，需要手动删除或使用整体替换。手机桌面启动器图标需要重新构建安装包才能更换。
