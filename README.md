# 大学课表 · Univ Timetable

把**教务系统里的课表**变成手机上一眼看懂的课表 App（Expo / React Native / TypeScript）。

核心思路：**把最不稳定、最脏的"爬教务系统"交给通用 AI agent，App 只消费一份稳定的数据契约**。
教务系统怎么改版，App 都不用改。

> 数据契约：`univ-timetable/v1`　·　当前版本：**v1.7.2**　·　平台：Android（APK）

---

## 下载安装

1. 打开 **[Releases](https://github.com/rainthink-vanilla/univ-timetable/releases/latest)** 下载最新的 `univ-timetable-x.y.z.apk`；
2. 手机上点击安装（首次需允许"此来源"安装未知应用）；
3. 打开 App → 按 **[使用教程](docs/使用教程.md)** 走一遍：填模板 → 让 agent 爬课表 → 导入。

> 升级：下载新版 APK **覆盖安装**，课表与设置都会保留。

**第一次用请直接看教程**：[`docs/使用教程.md`](docs/使用教程.md)（从安装到用上，含 FAQ 与排错）。

## 它解决什么问题

| 问题 | 这个项目的做法 |
| --- | --- |
| 各校教务系统千差万别，爬虫写一个坏一个 | 爬取交给通用 AI agent + 一份引导提示词；App 不含任何学校专用代码 |
| 课表数据格式乱七八糟 | 定义统一契约：人可读的 Markdown 表格 + 机器可读的 JSON 代码块，App 三层降级解析 |
| 各校作息不同（8:00 与 8:30 上课） | 契约支持**节次时间表**，导入时同步；也能在设置里手动改 |
| 课表只能自己看 | 一键分享给对方：对方导入即可还原（可选择是否套用你的主题） |

## 功能一览（v1.7.2）

### 看课表

| 功能 | 说明 |
| --- | --- |
| **日视图** | 左右滑动切换周一到周日，自动高亮「今天」与「正在上课」 |
| **周视图** | 7 天 × 节次网格；**左侧时间栏显示每节的开始与结束时间**；课程块内**地点自动换行、尽量显示全** |
| **全视图** | 整学期按周列出，点周块可**展开该周课表网格**；当前周高亮，一键「回到本周」 |
| **周次预览** | 以正常课表的样子提前查看任意一周，可前后翻周、数字胶囊直达 |
| **灵动岛** | 顶部胶囊显示当前周 / 日期 / 下一节课，可展开详情 |
| **重叠课程分列** | 同一时段两门课**并排显示各占半列**，不再互相遮挡 |
| **边栏时间轴** | 每节标注开始 + 结束时间（各校作息不同，按设置显示） |

### 导入与数据

| 功能 | 说明 |
| --- | --- |
| **文件导入** | 系统文件选择器读取 agent 生成的 `.md` / `.json`，预览后勾选课程导入 |
| **三种导入策略** | 更新合并（默认）/ 整体替换 / 追加 |
| **一格多天** | 数据里写 `周六、周日`、`6,7`、`周末`、`工作日`、`每天` 等，自动拆成多条课程 |
| **AI 导入**（兜底） | 粘贴课表文本或上传截图，由 AI 解析；兼容 DeepSeek / OpenAI / Moonshot / 通义千问 / 智谱 GLM |
| **手动添加** | 完整表单；**星期可多选**（选 2 天即生成 2 条，方便单独改某一天） |
| **导入后安全提醒** | 弹窗提醒立即修改教务系统密码，可一键跳转 |
| **课表自检** | 按星期分布 / 重复项 / 星期字段异常 / 周六周日专项提示 + 修复建议，报告可分享 |

### 外观

| 功能 | 说明 |
| --- | --- |
| **强调色** | 选中即刻生效（按钮、胶囊、标签高亮、浮动按钮…） |
| **自定义背景图** | 选图后进入**裁剪**：拖动 / 双指缩放 / 比例（全屏·9:16·1:1）；显示"建议目标尺寸"与清晰度分级；**非破坏性裁剪**，随时重裁不掉画质 |
| **背景遮罩** | 5 档，背景越花可调越深 |
| **应用内图标** | 底部三个标签**都能单独换**：上传图片（1:1 裁剪）或选 emoji |
| **分类抽屉设置页** | 设置项按功能分六类、可折叠；也可一键关掉折叠、全部平铺 |

### 分享

| 功能 | 说明 |
| --- | --- |
| **分享课表** | 系统分享面板（微信 / QQ / 邮件），面板内可「复制」 |
| **分享简版文本** | 按天分组的紧凑文本，适合发聊天窗口 |
| **接收同学课表** | 预览后选择「用自己的主题」或「应用对方主题」导入 |

## 开发与验证

```bash
npm install
npm run typecheck      # TypeScript 类型检查（0 错误）
npm test               # 单元测试 69 项（契约解析 31 + 周次日期 7 + 裁剪/分列/尺寸/兼容/自检 31）
npm run verify         # 无头浏览器断言：灵动岛 6 + 周次列表 13 + 周次预览 14 + v1.6 33 + v1.7.0 30 + v1.7.1 24 + v1.7.2 11
npm run verify:apk     # APK 二进制校验（签名 / bundle / 原生模块 / 版本号，13 项）
npx expo start         # 开发服务器（Expo Go 扫码）
```

构建安装包（本机无 Android SDK，用 EAS 云构建）：

```bash
npx eas-cli build -p android --profile preview    # 产出可直接安装的 apk
```

> 验证脚本需要本机有 Chrome / Edge（`scripts/lib/browser.mjs` 会自动找）。
> 受限沙箱里 `node --test`、Metro 打包、启动无头浏览器都需要派生进程，可能被拒（`spawn EPERM`），
> 换到普通终端运行即可。

**验证脚本在做真事，不只是跑一遍不报错**：无头浏览器里注入真实 PNG/触摸事件、
拦截文件选择框上传图片、逐像素量课程块位置（例如"七列等宽、块不越出自己那一列"、
"重叠课程两块的矩形不相交"）、把打包产物与上一版做**逐字节差集**确认改动真的进了包。

## 数据契约速览

````markdown
## 一、课表元信息
| 学校 | 示例大学 |
| 学期开始日期 | 2025-09-01 |
| 学期总周数 | 20 |

## 二、节次时间表
| 节次 | 开始 | 结束 |
| 1 | 08:30 | 09:15 |

## 三、课程明细
| 课程名称 | 教师 | 地点 | 星期 | 节次 | 周次 |
| 高等数学A | 张三 | 教一101 | 周一 | 1-2 | 1-16 |
| 周末实验 | 王五 | 实验楼A | 周六、周日 | 5-6 | 1-16 |

## 四、机器可读数据
```json
{
  "contract": "univ-timetable/v1",
  "meta": { "school": "示例大学", "semesterStart": "2025-09-01", "totalWeeks": 20 },
  "periods": [{ "index": 1, "start": "08:30", "end": "09:15" }],
  "courses": [
    { "name": "高等数学A", "teacher": "张三", "location": "教一101",
      "dayOfWeek": 1, "startPeriod": 1, "endPeriod": 2, "weeks": [1,2,3,4,5,6,7,8] }
  ]
}
```
````

解析策略（三层降级）：**JSON 代码块 → Markdown 表格 → 宽松兜底**；表格与 JSON 冲突时以 JSON 为准。
完整规范与字段别名见 `docs/01-用户信息表与爬取引导.md`。

## 隐私与安全

- **教务系统密码不进 App**：它只出现在你自己填写的引导文件里；App 不接收、不存储、不写日志；
- **课表只存在本机**：`AsyncStorage`，App 不联网同步；导入完成后会提醒你**立即修改教务系统密码**；
- **图片只在应用目录**：自定义背景与图标的图片复制进 App 自己的目录，裁剪只记录范围、不改动原图；
- **分享由你发起**：只有你点「分享」时内容才离开设备；「分享自检报告」同理；
- ⚠️ **不要把你填好账号密码的引导文件提交到 git 或发给别人**。

## 已知限制

- 手机**桌面启动器图标**无法在应用内更换（由安装包决定，需重新打包）；
- 增量更新**不会自动删除**教务系统里已取消的课程（需手动删或整体替换）；
- 毛玻璃效果开关为预留，未实现；
- 只发布过 **Android** 安装包；iOS 未验证；
- 课表数据格式以契约为准，非标准文件会走"宽松兜底"解析并给出警告。
